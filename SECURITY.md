# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `1976114118@qq.com`. Do not include passwords, cookies, access tokens, private student data or other third-party secrets in a public issue.

Include the affected version, operating system, impact and minimal reproduction steps. The maintainer will acknowledge actionable reports, investigate them and coordinate a fix before public disclosure when appropriate.

## Supported release

Security fixes target the latest published Fuck DDL release. Unsigned preview builds are clearly marked and are not represented as trusted signed releases.
