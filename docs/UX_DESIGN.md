# UX 与视觉设计方案

版本：`0.1-draft`  
状态：已选择视觉方案 1“DDL 跑道”

产品名称：`Fuck DDL`

## 1. 设计方向

采用 Microsoft Fluent 的 Windows 亲和性，结合 Linear 式紧凑信息布局。整体克制，DDL 状态是唯一使用高饱和颜色的视觉层级。

名称语气直接，但界面文案保持清楚、中性且可操作，不使用羞辱性提醒。品牌名称可在标题栏、登录页和关于页完整显示；高频操作区优先使用简洁图标或 `FDDL` 紧凑标记，避免名称抢占任务信息层级。

产品的具体主题是“时间正在变窄”。界面的标志性元素是 **DDL 跑道**：每张任务卡上的完成程度条与非线性剩余时间条并排出现，使用户一眼看出“还剩多少工作”和“还剩多少时间”。

已生成三套可比较方案，用户选择“DDL 跑道”为实现目标。视觉真值文件：`docs/design/ddl-runway-selected.png`。

## 2. 视觉原则

- 信息优先：默认视图首先展示任务名称、DDL、两个进度条和开始按钮。
- 紧张感有边界：普通任务保持中性，只有 1 天内使用红色和加粗。
- 密度可控：桌面默认紧凑，触屏与窄屏增大点击区域。
- 状态不只靠颜色：红色同时配合文案、图标和字重；灰色过期项明确显示“过期未完成”。
- 动画服务判断：进度条按分钟重算，不持续流动；仅状态跨阈值时使用短促过渡。

## 3. 初始设计令牌

最终颜色需在视觉稿阶段校准，初始令牌如下：

| 角色          | 颜色      | 用途                 |
| ------------- | --------- | -------------------- |
| Ink           | `#18212F` | 主文字和高对比图标   |
| Canvas        | `#F7F8FA` | 页面背景             |
| Surface       | `#FFFFFF` | 卡片和弹层           |
| Focus Blue    | `#315EFB` | 主操作、焦点和完成度 |
| Warning Amber | `#D97706` | 2 天内重点状态       |
| Critical Red  | `#D92D20` | 1 天内紧急状态       |
| Expired Gray  | `#7A818D` | 已过期状态           |

深色模式使用同一语义令牌重新映射，不直接反色。支持 Windows 系统主题并允许手动覆盖。

字体：

- 界面与中文正文：`Segoe UI Variable`, `Noto Sans SC`, `system-ui`。
- 计时、百分比和倒计时：`JetBrains Mono`, `Cascadia Mono`, `monospace`。
- 字号采用 12 / 14 / 16 / 20 / 28 的有限比例，避免仪表盘式大数字泛滥。

间距以 4px 为基础，常用 8 / 12 / 16 / 24。卡片圆角 8px，弹层 12px；阴影只用于浮层，列表用边框和间距分组。

## 4. 桌面布局

```text
┌─────────────────────────────────────────────────────────────────┐
│ 顶栏：快速添加 / 全局搜索 / 当前计时 / 同步状态 / 账户          │
├──────────────┬───────────────────────────────────┬──────────────┤
│ 导航         │ 最近 DDL                         │ 今日摘要     │
│              │                                   │              │
│ 最近 DDL     │ [任务卡：标题、来源、DDL]         │ 工作时间     │
│ 今日计划     │ [完成程度条][剩余时间条] [开始]   │ 完成率       │
│ 今日完成     │                                   │              │
│ 收件箱       │                                   │ 当前专注     │
│ 目标         │ [越快截止越靠上，较远任务在下方]  │              │
│ 项目         │ [任务卡……]                        │              │
│ 过期任务     │                                   │              │
│ 统计         │                                   │              │
│ 成绩         │ [得分率 + 成绩状态带 + 成绩账本]   │              │
│              │                                   │              │
│ 集成 / 设置  │                                   │              │
└──────────────┴───────────────────────────────────┴──────────────┘
```

- 左侧导航宽度约 220px，可折叠为图标栏。
- 主内容控制在易扫描宽度，不让任务卡横向拉满大屏。
- 右侧摘要宽度约 260px；窗口较窄时折叠到侧边抽屉。
- 当前计时始终可见，开始新任务时明确提示将暂停上一任务。
- 右侧专注面板必须提供清晰的任务选择器；选中任务行和选择器的当前值保持一致。

## 5. 网页与移动布局

- 宽屏网页与桌面端共享布局和组件。
- 平板隐藏右侧摘要，将指标放到列表顶部的紧凑行。
- 手机网页采用底部导航：DDL、今日、添加、目标、更多。
- 手机任务卡依次显示标题、DDL、双进度条和主操作；次要字段进入详情。
- 网页端不显示 Windows 专属能力入口，集成页只展示其同步状态和只读说明。

## 6. 核心屏幕

### 6.1 GitHub 登录

- 单一主操作“使用 GitHub 登录”。
- 显示白名单说明、隐私概要和登录失败的明确处理。
- 不出现邮箱密码输入框。

### 6.2 最近 DDL

- 默认按手动置顶、2 小时自动置顶和综合分数排序。
- 除手动置顶外，任务从上到下呈现“快截止 → 较远 DDL”，不使用横向时间分区打断顺序。
- 支持按来源、项目和状态筛选。
- 任务卡提供：开始、置顶、打开详情；外部任务显示只读来源标记。

### 6.3 快速添加

- 第一行只要求名称、DDL 和完成程度默认值。
- 预计耗时、重要程度、项目等放在“更多选项”。
- 支持键盘完成全流程，保存后焦点回到输入框。

### 6.4 目标

- 左侧导航固定显示“目标”。
- 目标列表用进度、目标日期和下一项任务表达状态，不使用装饰性大卡片。
- 目标详情按“下一步、关联项目、全部任务、复盘记录”组织。
- 从目标详情新增任务时自动带入目标归属，但仍要求填写任务 DDL。

### 6.5 今日计划

- 软件建议位于左侧，确认后的时间轴位于右侧。
- 每条建议解释排序原因，例如“24 小时内到期，尚未完成 70%”。
- 用户可拖动排序和时段，不隐藏自动建议依据。

### 6.6 今日完成

- 采用按完成时间倒序的窄行账本，不复用最近 DDL 的可操作任务表。
- 每行显示完成时间、任务标题、来源和原 DDL；完成标记使用绿色印章与纵向时间线，其他页面保持克制。
- 空状态解释哪些行为会留下完成记录，不把过期或同步缺失描述成完成。
- 手动完成记录可点击进入编辑/删除弹层；来源完成记录不显示可修改入口。

### 6.7 专注计时

- 默认 25+5，切换模式最多两次点击。
- 最近 DDL 页右栏显示完整计时卡；计时开始后所有页面底部显示可展开的迷你计时条。
- 计时卡只保留任务、当前阶段、剩余/已用时间、暂停、停止和统一休息按钮。
- “休息额度账本”以穿过零点的刻度条显示：正值使用蓝色，负值使用红色，并同时显示准确分钟数。
- 专注结束弹窗提供开始休息、继续一轮和结束；手动任务随后显示完成度滑杆，外部任务显示同步状态。
- 休息为正向计时，统一按钮开始、用户手动结束；额度归零后继续计为负值。
- 休息结束使用无声音系统通知；不强制进入下一个工作段。
- 顶栏计时按钮和底部迷你条保持同一状态，避免出现两个独立计时器。

### 6.8 过期任务

- 分为“过期未完成”“过期后完成”“已放弃”。
- 手动任务提供完成、延期、放弃。
- 外部任务不显示可修改操作，只显示刷新来源和打开网页。

### 6.9 集成

- 每个来源显示连接状态、最后成功时间、同步数量和最近错误。
- PTA 和学在浙大通过独立登录窗口连接。
- 学在浙大错误状态明确提示 VPN 条件。

## 7. Edge 提醒

- 非白名单域名连续停留 10 分钟时先显示边缘提示；超过阈值后自动暂停专注并进入摸鱼计时。
- 文案保持中性：“已暂停专注；当前网站开始计入摸鱼时间。”
- 标签格式为 `摸鱼 · example.com`，不显示路径、查询或网页标题。
- 离开网站后仅发送“继续专注”通知，不自动恢复。
- 用户可选择仅本轮允许或永久加入白名单；不使用羞辱性措辞或强制封锁网站。

## 8. 空状态与错误

- 空任务列表：“还没有临近任务。添加任务或连接任务来源。”
- 同步失败：说明来源、原因、上次成功时间和唯一下一步。

### 成绩页

- 左侧主导航使用“成绩”作为独立入口，不与今日完成或过期任务混在一起。
- 页首只展示一个主指标“可计算得分率”；右侧成绩状态带每格对应一项来源成绩，高度表示该项得分率，斜纹表示未公布，红色短格表示错过 DDL。
- 列表明确写“已出分 / 未公布 / 错过 DDL / 待确认”。未公布显示破折号，不显示 0；错过 DDL 显示文字而不是伪造一个数字成绩。
- 过滤器使用来源和状态两个稳定维度；桌面表格在窄屏改为卡片顺序，保留键盘焦点和文本状态，不只依赖颜色。
- 离线：保持本地可编辑，显示“更改将在联网后同步”。
- 冲突：默认显示合并结果；只有同字段冲突时才要求用户选择。

## 9. 可访问性

- 最低目标 WCAG 2.2 AA。
- 所有交互支持键盘，焦点环不可被取消。
- 颜色对比满足正文 4.5:1；紧急状态有文本和图标冗余。
- 支持 `prefers-reduced-motion`。
- 图表提供表格或文字摘要。
- 触控目标不小于 44×44 CSS px。
