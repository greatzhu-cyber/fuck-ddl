# 产品需求说明

版本：`0.1-draft`  
日期：`2026-07-06`  
状态：已批准

产品名称：`Fuck DDL`  
技术标识：`fuck-ddl`

## 1. 产品定义

`Fuck DDL` 是一套个人工作记录器，核心目标不是堆叠待办，而是完成以下闭环：

> 快速收集任务 → 判断现在最该做什么 → 专注计时 → 自动留下记录 → 每日和每周复盘

主要使用者目前是项目所有者。数据模型按多用户隔离设计，第一版只允许 GitHub 白名单中的账号注册。

## 2. 成功标准

- 用户能在 10 秒内添加一个带 DDL 的任务。
- 默认页面能清楚回答“现在最应该做什么”。
- 今日工作时间由任务计时自动汇总，按用户本地自然日在 00:00 切日，允许事后补录。
- 完成任务从当前 DDL 移除后仍可在“今日完成”中追溯。
- PTA 和学在浙大任务可自动进入统一任务表，且不会重复。
- 桌面离线时可正常工作，联网后恢复同步。
- 任何云端或适配器故障都不能导致本地任务丢失。

## 3. 客户端范围

| 能力                         | Windows 桌面端 | 响应式网页端       |
| ---------------------------- | -------------- | ------------------ |
| 查看和编辑手动任务           | 是             | 是                 |
| 查看外部只读任务             | 是             | 是                 |
| 新增任务、子任务、DDL、进度  | 是             | 是                 |
| 任务计时与补录               | 是             | 是，补录和基础计时 |
| 离线完整读写                 | 是             | 否，后续阶段评估   |
| Windows 通知、托盘、开机启动 | 是             | 否                 |
| 应用类别统计                 | 是             | 否                 |
| Edge 域名提醒                | 是             | 否                 |
| PTA/学在浙大认证与抓取       | 是             | 否                 |
| 统计与复盘                   | 是             | 是                 |

## 4. 信息架构

主导航：

- 最近 DDL：默认页面。
- 今日计划：软件建议、用户确认、生成当天时间表。
- 今日完成：记录本地当天明确完成并从当前 DDL 移除的任务。
- 收件箱：快速捕获尚未整理的任务。
- 目标：管理长期目标，并查看其关联项目、任务和整体进度。
- 项目：按课程或项目查看任务。
- 过期任务：过期未完成、已完成和放弃统计。
- 统计：工作时间、完成率、计划与实际差异等。
- 成绩：归档 PTA 与学在浙大已结束任务的成绩、未公布和错过 DDL。
- 集成：PTA、学在浙大、Edge 扩展。
- 设置：通知、计时、白名单、数据导出与隐私。

侧边栏常驻展示今日工作时间和今日任务完成率。完成率定义为“今日完成任务数 ÷（今日完成任务数 + 今天仍到期的未完成任务数）”；分母为零时显示“—”。

## 5. 目标模型

- 用户可以创建、编辑、归档或删除目标；删除目标只解除任务关联，不删除任务。
- 目标包含名称、说明、可选目标日期和状态。
- 一个目标可以关联多个项目和任务；一个任务第一版只归属一个目标，避免统计重复。
- 有关联任务时，目标进度按关联任务权重自动计算；没有关联任务时允许手动填写。
- 目标页展示当前目标、已归档目标、总体进度、最近里程碑和下一项任务。
- 目标不替代任务 DDL，也不直接参与 DDL 优先级公式；它作为筛选、规划和复盘维度。

## 6. 任务模型

### 6.1 必填与选填字段

必填：

- 任务名称。
- DDL，精确到分钟，默认使用用户时区。
- 完成程度。新建任务默认为 0%，用户不必重复填写。

手动任务可在最近 DDL、过期任务和今日完成中编辑或删除；来源同步任务的来源字段与完成状态只读。

选填：

- 预计耗时。
- 重要程度：低、普通、重要、关键；默认普通。
- 所属项目。
- 所属目标。
- 最早开始时间。
- 是否可拆分。
- 备注和标签。

系统字段：

- 数据来源 `manual | pintia | zju_courses`。
- 来源 ID 和来源 URL。
- 所有者、版本号、创建/更新时间、删除时间。
- 同步状态与最后同步时间。

### 6.2 完成程度

- 手动任务无子任务时，通过百分比滑块或数字输入更新。
- 手动任务有子任务时，由已完成子任务权重自动计算，禁止手动覆盖。
- PTA 题目集作为主任务，题目作为子任务；进度由网页已完成题数计算。
- 学在浙大的课程作为项目，作业/待办作为任务；若网页提供子项则映射为子任务。
- 外部同步任务的名称、DDL、完成程度和状态只读。

## 7. DDL 状态与剩余时间条

剩余时间条从 7 天时的 100% 开始，以非线性速度下降。设剩余小时数为 `t`，时间条剩余比例为 `R`：

```text
t >= 168:        R = 1.00
48 <= t < 168:   R = 0.75 + 0.25 * (t - 48) / 120
24 <= t < 48:    R = 0.50 + 0.25 * (t - 24) / 24
2 <= t < 24:     R = 0.15 + 0.35 * (t - 2) / 22
0 < t < 2:       R = 0.15 * t / 2
t <= 0:          R = 0
```

界面每分钟重算一次，不运行持续动画。

状态规则：

- 7 天以上：正常。
- 2 天以内：重点提醒。
- 1 天以内：紧急提醒，文字加粗变红。
- 2 小时以内：最后期限状态，自动置顶。
- 已过期：从正常列表移入过期区域，使用灰色，但必须保留清晰的“未完成”文本提示。

手动过期任务必须选择：已完成、延期并设置新 DDL、放弃。外部任务只接受网页同步状态。

## 8. 自动排序

设：

- `U = 1 - R`，时间紧迫度。
- `P` 为完成比例，取值 0 到 1。
- `I` 为重要程度：低 0.25、普通 0.50、重要 0.75、关键 1.00。

综合分数：

```text
Score = 100 * (0.65 * U + 0.20 * (1 - P) + 0.15 * I)
```

排序顺序：

1. 手动置顶。
2. 剩余 2 小时内的自动置顶。
3. 综合分数从高到低。
4. 分数相同时 DDL 更近者优先。
5. 仍相同时完成程度更低者优先。
6. 已过期任务不参与正常排序。

除用户主动手动置顶外，列表必须保持“越快截止越靠上、DDL 越远越靠下”的视觉顺序。不得使用随机推荐或跨区块布局破坏这一心智模型。

## 9. 今日计划

- 软件按优先级分数、预计耗时和历史可用时间生成建议。
- 用户确认后形成当天时间表，可拖动调整。
- 作息不固定；软件根据近 14 天任务计时学习常见工作时段，只作为建议。
- 未填写预计耗时时，先安排 30 分钟探索时段。
- 第一次计时后可根据进度变化生成剩余耗时建议，但不强制修改。
- 软件不能仅凭键鼠活动判断工作或休息。

## 10. 计时

- 同一时刻只能运行一个任务计时器。
- 开始新任务时自动暂停当前任务并记录切换。
- 默认番茄钟为 25 分钟工作 + 5 分钟休息。
- 可切换为 50+10、自由计时或用户保存的自定义模式；自定义专注为 15–180 分钟、休息为 5–60 分钟，最多保存 5 套。
- 番茄钟默认绑定任务，也允许不绑定任务的“临时专注”。
- 暂停时间不计入工作；关闭程序立即停止所有计时，并自动保存此前的实际工作或休息时长。
- 完整完成预设专注段才计为一个完成番茄；提前结束仍记录实际工作时间，但标记为未完成专注段。
- 自由计时正向累计、由用户停止，不计入完成番茄数。
- 单次实际专注满 15 分钟后，按当前模式的工作/休息比例累计休息额度；自由计时默认按 20%累计。
- 所有未使用的休息额度仅在当天有效，次日清零。
- 只有一个“开始休息”入口。休息没有强制结束点，持续休息会把额度扣至负数，后续专注先偿还负额度。
- 最近 7 天内有 3 天出现负额度时，建议用户提高休息比例，但不自动修改模式。
- 专注段结束只使用无声音弹窗，提供开始休息、继续同长度一轮和结束；不会自动替用户选择。
- 关闭程序时不弹出确认，默认停止、保存并记录实际时长。
- 支持在当天时间轴中补录、拆分和重新分配时间。
- 预计耗时可换算为预计番茄数，并显示实际专注与预计值对比；计时不会自动修改任务完成程度。
- 手动任务专注结束时显示完成度滑杆，默认保留当前值并允许跳过；外部任务改为立即读取来源状态。

## 11. 通知

- DDL 剩余 2 天：重点提醒。
- DDL 剩余 24 小时：紧急提醒。
- DDL 剩余 2 小时：最后期限提醒并自动置顶。
- 通知去重，避免应用重启后重复发送。
- Windows 原生通知第一版只承诺点击后打开对应任务；通知内操作按钮需在实机验证后决定。
- 番茄结束和恢复专注通知不播放声音；应用最小化时使用 Windows 通知，点击后打开应用内操作弹窗。
- 所有提醒均可在设置中关闭或调整。

## 12. Edge 防分心提醒

- 配套 Microsoft Edge Manifest V3 扩展只读取活动标签页的域名。
- 专注期间，非白名单域名在前台连续活跃超过 10 分钟后自动暂停当前专注。
- 从第 11 分钟开始扣减休息额度并记录为“摸鱼”；记录只显示域名，不保存完整 URL。
- 离开该域名后不自动恢复专注，只发送无声音通知，由用户点击继续。
- `pintia.cn` 和 `courses.zju.edu.cn` 默认在工作白名单。
- 用户可把域名设为仅本次专注允许或永久允许；应用不根据访问频率自动加入白名单。
- 不读取完整 URL、标题、文件名、搜索词、页面内容或输入内容。
- 域名记录只在本机保存；云端只同步用户明确选择的统计汇总。

## 13. 外部任务集成

### 13.1 通用规则

- 用户在独立登录窗口中直接登录来源网站，应用不接触明文密码。
- 认证会话只存本机安全存储。
- 启动应用时同步一次，运行期间每 45 分钟同步一次，并提供立即更新按钮。
- 外部任务专注结束时额外刷新对应任务；同步进行中禁用重复触发。
- 使用 `source + source_id` 幂等更新，不重复创建任务。
- 失败时保留上次成功数据，指数退避，明确显示最后成功时间和原因。
- 只有已认证且成功完成的全量快照为空时，才从活跃列表移出缺失的来源任务；任务级刷新不得清理同来源的其他任务。
- 不绕过验证码、MFA、登录限制或网站访问控制。

### 13.2 PTA

- 题目集映射为主任务，题目映射为子任务。
- 完成程度按已完成题数计算。
- 用户可编辑本地备注、预计耗时和计时记录；同步字段只读。

### 13.3 浙江大学课程平台

- URL：`https://courses.zju.edu.cn/user/index`。
- 课程映射为项目，待办/作业映射为任务。
- 当前环境在 VPN 下无法访问；正式适配器必须在用户关闭 VPN 后完成实机验证。
- 连接失败时提示关闭 VPN 后重试，应用不得自行修改代理或 VPN。

## 14. 账户与同步

- 首次使用通过 GitHub 注册和登录，不提供本地密码登录。
- 第一版只允许 GitHub 白名单中的用户创建账户。
- GitHub 用户 ID 是稳定身份键，不使用可变用户名或邮箱作为主键。
- Windows 桌面端支持离线修改，使用 outbox 联网重放。
- 云端保存版本历史；非重叠修改自动合并，重叠修改保留上一版本供恢复。
- 导出格式：JSON、CSV、Markdown。
- 删除任务进入回收站，默认保留 30 天。

## 15. 统计与复盘

核心统计：

- 今日和每周总工作时间。
- 今日任务完成率。
- 今日完成任务账本，保留任务标题、来源、原 DDL 和完成时间。
- 预计耗时与实际耗时差异。

扩展统计：

- 项目投入时间、逾期率、PTA 完成题数趋势。
- 目标投入时间和目标完成趋势。
- 正式休息、摸鱼时间和休息额度正负变化。
- 摸鱼休息占比：`摸鱼时长 / (摸鱼时长 + 正式休息时长)`。
- 工作过程摸鱼率：`摸鱼时长 / (有效工作时长 + 摸鱼时长)`；正式休息不进入分母。
- 两个比例的分母为零时显示“暂无数据”。
- 每日时间轴、每日工作日志、每周复盘。

来源同步只有在平台明确返回完成状态时才写入完成账本；过期、任务缺失、登录失败和解析失败均不得计为完成。

### 15.1 成绩账本

- 成绩记录独立于活跃任务；任务从最近 DDL 移除后，历史成绩仍保留。
- 状态固定为 `published | unpublished | missed | unknown`。平台返回数字 0 且存在提交证据时是正常已出分 0 分；题目集关闭且无法开始、未答题，或作业截止且无提交证据时才是 `missed`。
- `--`、“不公布”、“尚未公布”必须保存为 `unpublished`，分数保持 `null`，禁止转换成 0。
- 可计算得分率只使用已公布且满分已知的记录；已知满分的 `missed` 按 0 分计入，未公布和未知状态不进入分母。
- 成绩入口支持按 PTA/学在浙大、课程和状态筛选，显示分数、满分、排名、来源、状态和原截止时间。
- 来源成绩只读；重复同步按来源和不可变来源 ID 幂等覆盖，不允许用户手改平台成绩。

## 16. 明确不做

第一版不做：

- 团队协作、任务指派或聊天。
- 自动生成内容的 AI 助手。
- 手机原生应用。
- 绕过第三方网站登录或自动修改第三方数据。
- 依据窗口标题或网页内容进行监控。

## 17. 第一版验收条件

- 目标与手动任务完整增删改查、双进度条、排序和过期状态通过边界测试。
- 桌面计时、托盘、通知、离线和恢复同步可用。
- 网页端可登录并完整编辑手动任务。
- RLS 隔离测试通过。
- Edge 扩展仅发送域名并能触发 10 分钟提醒。
- PTA 实机同步通过；学在浙大在关闭 VPN 后完成认证和同步验证。
- JSON 导出与备份恢复演练通过。
